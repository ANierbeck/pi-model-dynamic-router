# v1.7.0 Release Plan

> Status: prepared 2026-10-04. Per AGENTS.md §1 the tag/release/publish
> happens ONLY after the owner's explicit, version-named approval.

## Scope (since v1.6.0, 52 commits, PRs #4–#21)

- **ADR-0022**: the router never reads or writes Pi's auth.json — keys
  resolve exclusively via `modelRegistry.getApiKeyForProvider`.
- **ADR-0023**: tier routing restored — per-group `max_gdpval` cap and a
  relative `best_quality_window`; floors stay GDPval-only.
- **AA multi-benchmark sourcing**: `score_by: briefcase | coding` orders
  candidates within the admitted pool from the existing GDPval scrape
  payload (`Cache.capability_profiles`); missing data fails closed to
  GDPval. Shipped groups: planning by AA-Briefcase Elo, tactical by the
  SciCode/Terminal-Bench blend.
- **Cost display**: PAYG list prices for subscription models in the
  `/router` table (opus-5-5 $4/$20 instead of $0.0/$0.0); routing keeps the
  sunk-cost sentinel.
- **`score_by` in the dynamic-config sort path** (release-review fix): the
  generated config now mirrors routing's `score_by ?? 'gdpval'` instead of
  leaking the group name into column selection.
- Quality/infrastructure: red-first §4 rule + mutation spot-campaign
  (9/9), nightly Stryker mutation testing (decision core, report-only),
  Dependabot with policy (host never auto-bumped), user-first docs
  overhaul, test-suite hygiene (1261 passing / 3 skipped), duplicate-import
  fix, two load-flaky tests fixed with evidence-based budgets.

## Why 1.7.0 (not 1.6.1)

New backwards-compatible functionality (tier caps, score_by columns,
capability profiles, planning group, list-price display) → minor bump per
semver. All new config/cache fields are optional; 1.6.0 configs and caches
parse and behave identically until enriched by a scan.

3. `gh release create v1.7.0` with the CHANGELOG section as notes.
4. The `publish.yml` workflow runs `test` → `npm publish` on the release
   event; verify `npm view pi-model-dynamic-router version` shows `1.7.0`.
5. Post-release: CHANGELOG `[Unreleased]` section stays empty until the
   next change lands.
